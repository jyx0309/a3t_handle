# 控制与调参

## 入场与退出

沿用已验证的入场：读取低层命令缓存，返回高层回接到缓存姿态，低层 PV 到配置
中心，校验 Jacobian，再选择 MIT。切换后立即发首帧，不等首个定时器周期。
中心由配置关节角的 FK 定义，不把到达误差当作新中心。

启动前馈从当前模型重力开始。位置目标固定中心 0.5 秒，再用 0.5 秒 smoothstep
释放到实测位置目标。没有精确回中超时条件或额外 0.15 rad/s 启动门限；
保留启动中心偏差超过 0.03 rad、数据无效时的中止条件。

退出只执行 low_set_servo_enable(false) 和 set_low_mode(false)，随后 5 秒只读
观察，不追加高层切模式、复位或运动。观察高层模式与使能状态分别记录；
高层反馈已使能不等于退出失败，也绝不等于已安全下使能。
发生原始故障时不会因退出观察成功自动清除故障。操作者已在精简前版本验证循环，
本次结构重构仍需现场复验。

## 每周期算法

当前 `gravity.source=urdf`：使用本地 C++ 模型计算重力，替代 SDK 重力，二者不叠加。
URDF 路径相对 `handle.json` 所在目录解析，启动前加载；加载失败不发起运动，
运行计算失败停止且不静默回退 SDK。模型每次启动 MIT 重新加载，运行中不热加载。
根为 base_link，重力 [0,0,-9.81]；joint1..6 与 SDK 角度一致，两个手指按零开度计算。
独立对比表明当前模型对称手指开度影响很小，但不包含额外摄像头/支架或摩擦补偿。
该选择同时作用于启动首帧、正常手柄及纯重力测试，PV 到中心流程不变。

日志 `gravity`/`gravity_torque` 为本次选用模型的请求值，`sdk_gravity` 保留 SDK 对照，
`gravity_source` 明确来源；`sent_torque` 才是经过总力矩限幅/变化率后的最终前馈。
`gravity_model` 记录 URDF 路径、SHA256 和安装假设。SDK 动力学查询仍保留，失败仍会
按原逻辑计入通信失败；本地计算不代表完全脱离 SDK。
需要回退时，退出并停止程序，把 `gravity.source` 改为 `sdk` 后重启。

坐标使用 SDK 基坐标系。平移误差为 p - p_center，旋转误差使用最短四元数
旋转向量 current * inverse(center)，不是直接减欧拉角。

1. 误差经过死区与低通滤波；速度由原始误差差分并滤波得到。
2. 每轴虚拟力/力矩 W = -K_axis * e_filtered - D_axis * velocity - breakaway。
   K_axis 和 D_axis 均乘配置轴向缩放；breakaway 在死区外按 smoothstep 平滑增加，
   不乘轴向缩放。它是附加项，不保证合成输出有非零下限。
3. 使用已校验的 Jacobian 映射 tau_cartesian = J^T W。
4. 各关节辅助：clamp(kp*a*tanh((q_center-q)/a) - kd*dq, +/-assist_limit)。
   配置 activation_rad 对应 a（平滑尺度），不是开关门限。
5. 静摩擦辅助取当前 `tau_cartesian + tau_assist` 的方向，仅当该关节速度低于
   `static_friction_velocity_rad_s` 时平滑加入；回正请求或速度接近零时均连续渐变。
   它不是固定偏置，不参与纯重力测试，拖动时会降为零。
6. tau_ff = gravity + tau_cartesian + tau_assist + tau_static_friction，先绝对限幅，再变化率限幅。
6. 发送 low_mit_command(q_target, 0, tau_ff, kp, kd, reply)。正常手柄 q_target
   跟随实测位置并限制相邻成功命令步长；不是厂商位置环直接锁住中心。

正常进入优先使用显式 `mit.normal_joint_kp/kd`，当前为测试前日志确认的
kp=[80,80,50,50,50,50]、kd=[5,5,1,1,1,1]。设备回报的增益可能是上一条命令
留下的值，纯重力测试后为零，不能当作不可变的厂商默认值。
旧配置未提供这两组数组时，mit.joint_kp/kd 均为 0 才读取设备伺服增益；
此兼容路径禁止纯重力测试，避免再次污染下次启动的增益来源。
驱动的位置/速度反馈项不包含在前馈限幅中；SDK 力矩反馈不是独立测力传感器。
position_scale/rotation_scale 只缩放相对输出，不缩放虚拟回正力。

## 调参顺序

### 第一轮：降低运动阻尼，保留静态回正强度（2026-09-29）

只调整 `position_damping: 10 → 6`、`rotation_damping: 0.3 → 0.2`。
回退时恢复这两个旧值。刚度、轴向缩放、重力、关节辅助、厂商增益和所有保护不变。
停止手柄并正常返回高层后重启程序读取配置；不对运行中的手柄热改参数。

实际 XYZ 刚度仍是 [21, 21, 60] N/m，阻尼从 [3.5, 3.5, 10] 变为
[2.1, 2.1, 6] N·s/m；旋转刚度仍为各轴 0.75 N·m/rad，阻尼从
0.075 变为 0.05 N·m·s/rad。驱动 kd 仍另行叠加，不能把上述值当作总阻尼。
这是一组待现场验证的参数，不代表已达到六维等手感；也不会增加静止时的回正力。
暂不把 XYZ 刚度统一：直接降低 Z 刚度会削弱已不足的回正，直接提高 XY 又会加重阻力。

依据：会话 `20260929_113343_263` 中 3348 帧均返回成功，前馈限幅标记均为零。
最后约 2 秒 J3 位置不变，平均发送 -9.425 N·m，其中模型重力 -7.128、
笛卡尔项 -2.022、关节辅助 -0.275 N·m。没有明确松手记录，不能把这个差值
直接当作摩擦或重力误差，更不能直接作为固定补偿加入。

### 本轮现场对比

1. 保持工具、中心、负载不变，现场急停可及、人员避开运动路径；先进入手柄观察
   中心是否稳定。出现持续漂移、振荡或明显下坠即终止，不继续扩大行程。
2. 在已验证的安全范围内，依次单独试 ±X、±Y、±Z，先约 2 cm；
   再试三个旋转方向的正负约 3°。不要同时平移和旋转；不能保持纯轴运动时如实备注。
3. 每次记录“+X 松手”等明确时刻，安全松手观察 5 秒，记录残余偏移及是否振荡。
   不回中时记录结果，不继续叠加下一个方向；人工按现有流程恢复同一中心再试。
4. 每方向重复两次，尽量保持位移和速度相近。另选一方向以更慢速度重复，区分
   随速度变化的阻力与静止时卡住。没有独立测力设备时，方向手感只能定性比较。
5. 比较松手后 1/3/5 秒的位置、旋转误差、关节变化、力矩分项、限幅及发送周期。
   GUI 的六维相对输出不是原始位移；定量误差使用 `handle.csv` 的 raw_error。

本轮验收重点是运动阻力是否下降且无新增振荡，不宣称已经解决精确回中。
若低速阻力仍明显不同，检查 `static_friction_*` 的方向和幅值，以及关节辅助和厂商 kd
的方向映射。不能仅凭低速判定已松手，也不加入无人确认的持续积分加力。

| 参数组 | 影响 | 注意 |
| --- | --- | --- |
| position/rotation_stiffness | 平移/旋转回正强度 | 增大会同时增加拖动阻力 |
| position/rotation_damping | 运动中的阻尼 | 还叠加驱动 kd，不能仅按 GUI 数值判断 |
| position/rotation_axis_scale | 各轴刚度和阻尼倍率 | 当前 XYZ 不等刚度，不要归一化关节力矩 |
| return_breakaway、deadband、transition | 中心附近的回正 | 并非已辨识的摩擦补偿，不能保证精确回中 |
| joint_center_assist_* | 关节回正辅助 | 本轮上限 0.8 → 2.0 N·m，可能与末端柔顺手感互相影响 |
| static_friction_* | 低速、同向的关节静摩擦辅助 | 仅用已记录双向起动力矩的保守比例；运行中记录独立分项 |
| joint_torque_limit_nm、torque_rate_limit_nm_s | 前馈幅值/变化率 | 不为追求手感盲目放宽 |

同一姿态/工具，单方向小幅移动，备注明确松手时刻，比较误差、速度、gravity、
cartesian_torque、joint_assist_torque、static_friction_torque、sent_torque 和限幅状态。
每轮只改一组参数，停止手柄后应用。若松手后不动但有正确回正请求，不能只凭 SDK
反馈判断是摩擦还是负载残差；静摩擦项可依据双向起动力矩继续调整，但不使用积分加力。

### 本轮静摩擦与阻尼（2026-09-29）

`static_friction_positive_nm` / `static_friction_negative_nm` 来自已记录的中心附近双向
起动力矩，按方向分别设置为保守、低于实测起动力矩的辅助量。它只帮助已经存在的
回正请求跨越静摩擦：回正力小于 0.08 N·m 时渐入，关节速度在 0–0.03 rad/s 内渐出。
纯重力模式和正常拖动不会保留此项。

本轮将 `position_damping` 由 3.0 提至 3.5、`rotation_damping` 由 0.10 提至 0.12，
并将关节辅助 kd 同比提高 20%。关节回正上限由 0.8 提至 2.0 N·m，非重力合计上限由
2.0 提至 3.0 N·m；总关节力矩、变化率、工作空间与其他通用保护未放宽。

## 无刚度、无阻尼纯重力试验

先正常进入 MIT，到中心且启动保持结束后，点击 UI「纯重力测试（零刚度／零阻尼）」
并确认现场支撑、防坠和实体急停条件。过渡用 1 秒 smoothstep 将实际发送的驱动 kp/kd、
空间弹簧/阻尼/最低回正力以及关节辅助同步降到零；模型重力不缩放。
目标位置仍跟随实测，但纯重力阶段 kp=0，不再用于位置保持。正常配置不会被修改。

绝对力矩限幅、变化率、位置/工作空间、健康状态及看门狗仍有效；
主机速度门限是否启用由下方 `enforce_joint_velocity_limit` 开关决定。
因此过渡后也可能因限幅而不等于原始模型重力；不可将这类片段用于判断模型偏差。
`control_math` 记录 `gravity_test`、`interaction_scale` 和 `gravity_only_unlimited`；
只有后者为 true，且对应 `mit_result` 成功的帧才表示发送了未经限幅改变的纯模型重力。
`mit_input` 可核对实际零 kp/kd；SDK 成功不证明驱动端完全没有内置补偿。
`handle.csv` 和 UI 的虚拟力使用实际缩放后的空间力，纯重力阶段应为零。

从中心附近小范围姿态开始，停稳、安全松手并用备注记录姿态编号/松手时间，观察 3–5 秒。
记录实际关节漂移及模型/发送/反馈力矩；一旦明显下坠、加速或振荡立即按现场安全流程停止。
不要在失去平衡时扩大范围。无阻尼会漂移，且下使能退出也可能掉落，必须有安全支撑。
各姿态静止只能说明残差可能被静摩擦承受，不能证明重力完全准确。
未增加自动加力、摩擦辨识或自动恢复刚度：测试结束使用原「停止手柄并返回高层」，
下一次正常进入 MIT 恢复原手柄参数。之后再单独设计受限的正反向静摩擦试验。

2026-09-29 12:01 实测：J5 反馈速度 1.5751 rad/s 超过 1.57 rad/s 主机门限，
随后退出观察成功。12:02/12:03 重入失败不是速度故障或 202，而是设备回报六轴
kp/kd 均为零，被旧的自动读取增益校验拒绝。现使用上述显式正常增益修复来源问题，
不在退出时追加恢复刚度命令、不自动复位/使能，也不删除速度保护。

## 保留的保护与已知限制（通用）

按快速拖动测试要求，当前 `safety.enforce_joint_velocity_limit=false`，不再因主机
速度比例门限而退出 MIT；速度仍记录且必须为有限数。启动时 UI 消息和日志显式提示。
将此开关恢复为 true 即重新使用 `joint_velocity_fraction=0.50`；旧配置未提供开关时
默认开启。控制器自己的保护未修改，其他主机保护不变。无阻尼快速松手可能继续运动，
关闭这个门限不代表已验证快速交互安全。PV 到中心的到达速度判据仍保留。

连接/健康/使能/模式检查、有限数和维度校验、厂家关节限位及配置裕量、可选的主机速度
比例检查、工作空间、deadman（若要求）、看门狗、连续失败阈值、前馈限幅/变化率、
相邻命令步长仍有效。退出期间互斥所有新运动操作。

缓存回接和到中心仍为历史同步运动实现，急停不能依赖 GUI 事件及时处理。
工具由厂家上位机配置，日志保存动力学查询返回的工具索引；未知负载不会自动辨识。
退出观察无错误不保证物理停稳；SDK 成功返回不等于驱动执行完成。
