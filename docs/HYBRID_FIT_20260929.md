# 物理模型优先、剩余残差补偿：已部署版本

## 当前正式补偿

配置 `gravity.compensation.enabled=true` 时，重启后的 URDF 会话直接发送完整的
辨识物理模型加六轴残差（包含 J2）。旧的候选试验路径已移除：不再按 25% 缩放或
0.25 N·m 限幅，也没有位移/速度门限、30 秒计时或自动退出。

基础模型哈希、参数数量与有限性、残差范围仍在进入 MIT 前校验；不匹配即拒绝启动。
日志以 `urdf_compensated` 标识，并记录 `baseline_gravity`、
`compensated_physical_gravity`、`gravity_compensation_delta` 和 `compensated_gravity_total`。
要回退到未修正 URDF，将 `gravity.compensation.enabled` 设为 `false`，在退出 MIT 后重启。

以下为部署前离线拟合的依据。
使用同一 URDF 哈希下四组数据（第四组不完整），64 对成功测试。
阈值中点只是重力残差代理，依赖摩擦对称假设，不是真实重力测量。

复现（需 numpy/scipy）：

```bash
python3 tools/fit_gravity_hybrid.py config/gravity_gripper_can.urdf runtime_logs/20260929_191202_927/diagnostics.jsonl
python3 tests/test_gravity_hybrid.py
```

## 模型

固定机械臂连杆质量和关节几何，拟合 link2/3/4 的质心偏移，及夹爪质量和一阶质量矩。
连杆质心偏移限制为各轴 ±20 mm，夹爪质量变化 ±0.1 kg，等效质心偏移 ±30 mm。
这些是探索性先验，不是已核实的 CAD 容差。归一化参数采用固定 0.1 正则化权重。
先拟合物理项，再对 J2/J3/J4 剩余误差中位数取 50%，每关节限制 ±0.5 N·m。
残差仅在训练数据上求取；留出组不参与对应轮的任何拟合。

## 结果（N·m，中点预测 RMSE）

| 数据 | 原始 | 物理修正 | 物理＋残差 |
| --- | ---: | ---: | ---: |
| 全数据训练 | 0.448 | 0.195 | 0.157 |
| 留出组1 | 0.524 | 0.240 | 0.204 |
| 留出组2 | 0.379 | 0.146 | 0.126 |
| 留出组3 | 0.407 | 0.133 | 0.118 |
| 留出组4（部分） | 0.475 | 0.386 | 0.362 |

全数据拟合后的残差候选为 [0, +0.074610, -0.110151, -0.050609, 0, 0] N·m。
这是物理修正之后的剩余项，不能再叠加先前未做物理修正时的 J3/J4 偏置。
它不是静摩擦补偿，不随速度方向翻转。

13 个参数的矩阵秩仅为 10；link2 的 Y 质心偏移达到 -20 mm，夹爪质量变化达到 +0.1 kg 边界。
因此不能把这些参数解释为真实质量/质心，也不能认为已完成物理标定。
组4的验证误差仍明显较大；整个流程经过了数据驱动选择，仍需新的独立验证姿态。

## 前后姿态贡献核对

取每组首次 J2 测试的实际起始角度：原 URDF 的 J2 总重力为
[-0.234, -3.907, -0.128, -7.009] N·m，四组并未发生总力矩反号。
link2 的 J2 贡献为 [0.743, 0.323, 0.723, -0.024] N·m，确实在组4反号；
link3 贡献为 [1.213, -0.367, 1.211, -1.697] N·m。
这说明姿态影响已经进入模型，但不能用大臂视觉朝向直接推断总重力或残差的符号。

## 后续维护

新增辨识结果时，先使用独立姿态复测，再更新 `gravity.compensation` 中的整组参数、残差和
基础 URDF 哈希；不要将旧残差与新的物理参数混用。需要回退时关闭该配置项并重启会话。
